# Pagninilay — Laboratory 5

Ang object storage ay mas angkop sa pag-iimbak ng milyun-milyong larawan dahil hindi ito nililimitahan ng laki ng pisikal na disk. Sa block storage, parang nakadikit ka sa isang hard drive — kapag puno na, kailangan palitan. Sa object storage, patuloy lang ang pagdagdag ng espasyo nang hindi napapansin, at madaling mahanap ang bawat larawan dahil may sarili itong natatanging pangalan.

Malaki ang naging tulong ng Docker. Sa halip na manu-manong i-install ang lahat ng programa at ayusin ang mga setting, isang utos lang sa terminal at gumagana na agad ang MinIO. Tiyak na magkatugma ang kapaligiran at walang nawawalang bahagi.

Ang "bucket" ay ang pangunahing lalagyan sa object storage — parang isang espesyal na folder na may natatanging pangalan sa buong sistema. Dito inilalagay at inaayos ang lahat ng iniimbak na bagay.

Upang hindi mawala ang datos kapag nasira ang server, ang malalaking kumpanya ay gumagamit ng **replication** — inilalagay ang kopya ng datos sa iba't ibang lugar o bansa. Kapag nasira ang isa, mayroong ibang kopya na magagamit agad.

Lumalakas ang aking tiwala sa paggamit ng Linux command line. Nagsisimula na akong masanay sa pagtukoy ng tamang utos, pag-unawa sa mga mensahe, at paglutas ng problema nang mag-isa.
